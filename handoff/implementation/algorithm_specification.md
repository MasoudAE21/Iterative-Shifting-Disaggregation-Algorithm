# Implemented mathematical specification

The supplied version 2.0 handoff is retained as `supplied_specification.md` with its input hash in manifests. Quinn et al., Sensors 2025, 25, 895, Section 3, Eqs.9-23 and Algorithm 1 govern paper_reference. Customer allocations are an output extension beyond the paper's aggregate profile.

For each bill on its full inclusive interval, initialize a=B/L. Sum retained allocations in canonical customer/start/end/bill-ID order. For each of exactly R outer iterations, fit one SVD least-squares aggregate model and freeze p=X beta. Perform C full sequential sweeps. On every bill visit use current old=a, other=y-old, e=max(p-other,0), z=B*e/sum(e) and new=(1-alpha)*old+alpha*z. Restore y=other+new. Later bills see earlier updates; p is unchanged until the next outer fit. No independent customer models, stale simultaneous sweeps or target-truncated normalization exist.

Implementation policies: B=0 stays exactly zero. For sum(e)<=64*epsilon*L*max(1,max(abs(p)),max(abs(other))), keep the current allocation. Normalize via max(e) first; use compensated/accurate sums. Small roundoff reconciliation differences only are added to the largest allocation, earliest day on ties. Materially negative subtraction, nonfinite state or a correction beyond 1e-8+1e-10*abs(B) fails. Recompute the canonical compensated aggregate after each complete cycle; compare incremental drift with gamma_M*sum(abs(contributions))+M*bill_atol, record observed differences and then replace y. Reference and compiled shifting use the same compensated float64 sum algorithm and explicit z-then-blend arithmetic order. A real-data comparison rejected an earlier math.fsum/compensated split with a 0.00038314 maximum difference; the accepted implementation requires the declared per-value equality tolerance, without relaxing it. Export reconciliation additionally uses math.fsum for an independent check.

The paper reference fits every D day with unscaled [intercept,HDD65,HDD55,HDDW65,CDD65]. It uses rcond=max(N_fit,p)*epsilon and reports singular values, rank, deficient condition and zero columns. The full design is retained even if unidentified. The cohort adaptation instead uses only the fixed target-balanced population, fit rows F, centered/scaled [intercept,HDD65], and then exposure multiplication of every column including intercept. Exposure is covering-cohort-customer-count/cohort-size, including recorded zeros. Outside F this assumes covered cohort members have the same average weather response. Candidate failure of rank=p, N_fit>=max(30,5p) or condition<=1e8 causes whole-cohort uniform fallback; no ridge or hidden feature replacement.

Local weather points attach UTC from GMT metadata, convert to Asia/Tehran, and are linearly interpolated/integrated over local midnight-to-midnight. Bounding hourly points and no gap over an hour are required. Features transform the daily mean AFTER integration: F=1.8*C+32; mph=kmh/1.609344; HDD_b=max(b-F,0); CDD65=max(F-65,0). HDDW multiplies HDD by (152+mph)/160 at mph<=8, otherwise (72+mph)/80. Open-Meteo documents these variables as instantaneous ([hourly definitions](https://open-meteo.com/en/docs/historical-weather-api)); the exact local export processing remains provisional. The identical wind formula explicitly specifies mph and F in the [NMGC Revised 2024 IRP](https://www.nmgco.com/userfiles/files/50725%20Case%20No.%2024-00203-UT%20-%202025-05-07%20-%20NMGC%20-%20Revised%202024%20Integrated%20Resource%20Plan.pdf), PDF page 69, printed C-5. Both sources were inspected on 7 October 2026. These provenance statements support units/adapter conventions, not local daily load accuracy.

All accepted selected bills are retained, including those not touching the target. Paths B/C are compact full-interval uniform fallback plus null target days where no accepted bill exists. Cohort, fallback and combined observed-support aggregates are separate; the combined mixed-population sum never enters a regression. Baselines are independently normalized uniform and fixed (1+HDD65) weather weights; last OLS p is a non-reconciled diagnostic. Production was not run.
